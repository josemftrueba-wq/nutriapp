Política de Privacidad

1. Responsable del Tratamiento

NutriApp - Nutrición Profesional

2. Datos Recopilados

Recopilamos datos de salud y composición corporal (peso, mediciones, edad, sexo) con consentimiento explícito del cliente.

3. Consentimiento RGPD (Art. 9.2.a)

El usuario otorga consentimiento explícito para el tratamiento de datos de categoría especial (salud) necesario para análisis nutricional.

4. Servicios Terceros

Los datos se envían a Claude (Anthropic) únicamente para:

  • Extraer datos automáticamente de informes PDF/imagen
  • Generar propuestas de menús personalizados
  • Análisis nutricionales

5. Seguridad

Los datos se almacenan en Supabase con encriptación. La clave API de Claude nunca sale del servidor.

6. Derechos del Usuario

Tienes derecho a acceder, rectificar, suprimir u oponertes al tratamiento de tus datos. Contacta con el responsable.

7. Contacto

Para dudas sobre privacidad, contacta con el nutricionista responsable de la aplicación.
